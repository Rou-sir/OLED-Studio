# OLED UI 设计器需求文档

- 文档版本：0.1，待用户审核。
- 日期：2026-11-07。
- 产品定位：面向 U8g2 的离线、单色、像素级可视化 UI 设计与代码生成工具。
- 当前状态：基础设计器已交付；OLED 组件扩展分阶段进行，验收记录见 [audit.md](audit.md)。
- 配套报告：[需求与技术审计](audit.md)。

## 1. 已确认的需求

| 项目 | 已确认内容 |
|---|---|
| 运行方式 | HTML 浏览器应用，离线纯前端，构建产物可直接打开，不依赖后端 |
| 工作方式 | 参考 SquareLine 的项目、页面、组件树、属性面板、拖拽设计工作流，不复制其界面或资源 |
| 项目 | 创建、管理项目，配置屏幕参数 |
| 页面 | 一个项目管理多个 UI 页面，每个页面独立配置组件 |
| 必选组件 | 线条、圆、矩形、三角形、多边形、ASCII 文字、中文文字、图片；扩展阶段增加点、水平/垂直线、椭圆、圆弧/扇形、进度条、电池 |
| ASCII | 使用 U8g2 内置字体，按像素高度筛选并选择原生尺寸，不要求任意字号缩放 |
| 中文 | 导入已有 U8g2 字库，并内置 TTF/OTF 转 U8g2 字库工具 |
| 图片 | 内置图片取模工具，支持导入已有 XBM/U8g2 位图，提供资源管理器 |
| 导出 | Arduino、ESP-IDF、STM32 HAL 平台 UI 代码包与调用示例 |
| 驱动 | 不负责屏幕驱动、HAL 回调、初始化、接口接线或完整固件工程 |
| 第一版交互范围 | 静态页面设计、管理与导出；不含按钮事件、运行时变量绑定、动画和页面跳转编排 |

## 2. 术语与边界

- **显示设备**：项目唯一的目标逻辑画布，具有宽、高、方向等参数。
- **UI 页面**：同一显示设备上的一个设计页面；不是另一块物理 OLED。
- **组件**：页面上的一个绘制对象。组件树的顺序就是绘制顺序。
- **资源**：项目内共享的字库、取模图片及其来源与元数据。
- **取模**：将图片或字形转换为明确排列方式的单色像素数据。
- **导出目标**：Arduino、ESP-IDF、STM32 HAL，共用页面语义与代码生成规则，分别生成原生 U8G2 C++ / U8g2 C 调用，各自提供集成示例，不生成驱动。

第一版只承诺 U8g2 单色绘制，不实现 LVGL 控件运行时、彩色/灰度编辑、多设备同步、云端账号、协作、固件烧录。所谓“类似 SquareLine”指设计工作流，不意味着实现 LVGL 的全部功能。

## 3. 核心使用流程

1. 创建项目，填写名称并选择 OLED 逻辑尺寸。
2. 创建、命名和组织多个 UI 页面，选择默认页面。
3. 从组件面板添加对象，在画布中拖动，在属性面板精确修改。
4. 导入或制作图片资源；导入字库或从 TTF/OTF 生成中文字库。
5. 将文字、图片组件绑定到资源，检查缺字、越界和资源体积。
6. 保存项目备份，关闭并重新打开后继续编辑。
7. 检查导出诊断，选择 Arduino、ESP-IDF 或 STM32 HAL，下载 UI 源码和资源。
8. 用户在已有 U8g2 驱动工程中调用指定页面的绘制函数。

## 4. 界面结构

- 项目入口：项目列表、新建、导入、重命名、复制、删除、最近修改时间。
- 顶部工具栏：保存状态、撤销/重做、缩放、网格、预览、导出。
- 左侧：页面管理、组件面板、当前页面组件树。
- 中央：单色画布、像素网格、选框、控制点和参考线。
- 右侧：当前选中对象属性、资源绑定、输入错误与越界提示。
- 资源面板：图片库、字库、图片取模、字体转换任务和诊断。
- 预览模式：隐藏编辑辅助元素，只显示最终单色像素。

编辑画布允许用颜色区分选框等辅助元素；这些元素不属于最终 UI，也不得出现在导出位图或代码中。

## 5. 功能需求

### 5.1 项目管理

| 编号 | 要求 |
|---|---|
| PRJ-01 | 创建、打开、重命名、复制、删除项目；删除需确认 |
| PRJ-02 | 项目保存名称、说明、创建/修改时间、目标屏幕、页面、资源及格式版本 |
| PRJ-03 | 导入/导出独立项目包；完整项目包必须包含恢复编辑所需资源，不引用用户机器的绝对路径 |
| PRJ-04 | 自动保存、手动保存、保存状态、失败提示；未保存时切换项目或关闭需提示 |
| PRJ-05 | 项目导入须校验版本、数据结构、资源引用和大小；失败不得覆盖现有项目 |
| PRJ-06 | 复制项目时产生新项目标识，内部页面/组件/资源引用保持一致 |
| PRJ-07 | 发现更新版本的项目格式时明确拒绝或提供受支持的迁移，不静默丢失字段 |
| PRJ-08 | 启动和重开先进入独立项目卡片首页；预览项目默认页的真实 U8g2 像素，展示尺寸、页数和更新时间；卡片进入设计器，首页提供新建、导入、目录打开、重命名、复制及删除缓存 |

本地浏览器存储用于便利性保存，不等于可靠文件备份。直接打开 HTML 时，浏览器对存储和关闭提示存在限制；可下载、可重新导入的项目包是必须提供的持久化方式。

经追加确认，交付为单 HTML，不引入本地服务器。用户首次选择目录并授权后自动写入 `project.oled.zip`；重开按浏览器要求重新授权；始终支持完整项目包下载/导入。缓存保存与磁盘关闭写入成功必须分别显示。新项目不绑定旧目录，外部文件变更不得无提示覆盖。

### 5.2 目标屏幕参数

| 编号 | 要求 |
|---|---|
| DSP-01 | 提供 128×64、128×32、128×128 等常见尺寸预设，支持自定义像素宽高 |
| DSP-02 | 固定 1 bit 单色；区分预览显示主题与实际像素值，主题不能改变导出结果 |
| DSP-03 | 可记录控制器名称作为说明，不因此生成驱动代码 |
| DSP-04 | 方向可选 0°、90°、180°、270°；明确物理尺寸与旋转后的逻辑尺寸 |
| DSP-05 | 可记录全缓冲或页缓冲使用方式，用于集成说明；UI 绘制函数本身不负责刷屏 |
| DSP-06 | 修改尺寸前说明受影响页面，保留原组件坐标，不静默缩放或删除，标记越界对象 |
| DSP-07 | 设置并校验 U8g2 坐标位宽；超出所选构建能力的尺寸或参数必须阻止导出 |

画布使用旋转后的逻辑尺寸。方向由调用方配置 U8g2 rotation，UI 模块不再次旋转，避免双重旋转。自定义大尺寸不代表任意 OLED 驱动均支持；例如需要表示参数 256 时，应验证对应 U8g2 构建的 16 位坐标能力。

### 5.3 多页面管理

| 编号 | 要求 |
|---|---|
| PAG-01 | 创建、重命名、复制、删除、排序页面；项目至少保留一个页面 |
| PAG-02 | 页面具有稳定标识、显示名称和唯一导出符号；默认页面可设置 |
| PAG-03 | 切换页面保留对象数据；页面的编辑视图状态可独立保存 |
| PAG-04 | 页面共享项目资源，但各自维护组件与绘制顺序 |
| PAG-05 | 每页可设置背景像素值 0 或 1 |
| PAG-06 | 页面绘制函数和页面枚举用于调用方手动选择页面；不生成自动跳转逻辑 |

### 5.4 画布操作

| 编号 | 要求 |
|---|---|
| EDT-01 | 添加、选择、取消选择、拖动、复制、粘贴、删除组件 |
| EDT-02 | 支持多选、框选、整体移动和对齐；锁定对象不可被拖动 |
| EDT-03 | 方向键按 1 个逻辑像素移动；组合键按 10 个像素移动；输入框内不拦截编辑快捷键 |
| EDT-04 | 整数像素坐标、网格吸附开关、画布缩放与平移；缩放不修改实际对象尺寸 |
| EDT-05 | 矩形有尺寸控制点；圆有半径控制点；线段、三角形、多边形有顶点控制点 |
| EDT-06 | 支持置顶、置底、上移一层、下移一层；组件树与画布顺序同步 |
| EDT-07 | 单次拖动形成一次撤销记录；撤销/重做覆盖组件编辑、页面操作和资源绑定变化 |
| EDT-08 | 隐藏影响预览和导出；锁定只限制编辑，不影响导出 |
| EDT-09 | 越界对象有明确提示；预览和导出使用同样的裁剪规则 |
| EDT-10 | 组件树可以选中被覆盖或难以点击的对象 |
| EDT-11 | 深色三栏设计器：左侧页面/组件、中间画布、右侧属性；项目/屏幕和保存设置在独立面板，不常驻占用设计栏；保存后可返回项目首页 |
| EDT-12 | 新添加组件默认英文类型名与序号；保留已有名称和自定义重命名，中文界面标签不变 |
| EDT-13 | Ctrl+S 接管浏览器保存网页操作，保存当前项目；输入框和资源配置弹窗内有效，未提交资源配置不自动加入项目；磁盘结果仍按授权与保存状态显示 |
| EDT-14 | 选中控件显示左/右/上/下四条边界延伸参考线及坐标，多选使用整体包围框；拖动同步更新，纯预览和导出不包含辅助线 |

不默认提供任意角度旋转、斜切、透明度或任意线宽。第一版几何轮廓为 1 像素；图片调整尺寸在取模工具中重新生成资源，不隐式调用 U8g2 不具备的缩放能力。

### 5.5 组件与属性

通用属性：稳定 ID、名称、类型、可见性、锁定、层级、绘制像素值 0/1，以及组件特定几何信息。每个组件绘制前显式设置其所需状态，不能继承前一个组件的字体或位图模式。

| 类型 / 编号 | 可配置属性 | U8g2 映射与说明 |
|---|---|---|
| 线条 CMP-01 | 两端坐标 | `drawLine` / `u8g2_DrawLine`，含水平、垂直及斜线 |
| 圆 CMP-02 | 圆心、半径、轮廓/填充 | `drawCircle` / `drawDisc`；编辑边界框由圆心与半径计算 |
| 矩形 CMP-03 | 左上坐标、宽高、轮廓/填充、可选圆角半径 | `drawFrame` / `drawBox`，圆角用对应 RFrame/RBox |
| 三角形 CMP-04 | 三个顶点、轮廓/填充 | 轮廓由线段构成；填充使用 `drawTriangle` |
| 多边形 CMP-05 | 有序顶点列表、轮廓/填充；添加/删除/拖动顶点 | 至少三个不同顶点；支持简单凸/凹多边形；自交、孔洞和退化填充不支持，明确报错 |
| ASCII 文字 CMP-06 | 内容、内置字体、位置、对齐、行距、透明/实底模式 | 原生字库尺寸；文本只允许可打印 ASCII 与明确支持的换行 |
| 中文文字 CMP-07 | UTF-8 内容、字库、位置、对齐、行距、透明/实底模式 | 使用 `drawUTF8`；可混合中文、ASCII、数字、标点，但所选字库必须全部覆盖 |
| 图片 CMP-08 | 位图资源、左上坐标、透明/实底模式、绘制像素值 | `drawXBM` 或适配存储区域的 `drawXBMP`；像素尺寸取自资源 |

**文本规则：**

- 编辑器显示顶部位置与计算出的基线；实际导出遵循 U8g2 字形度量，不能将网页文本左上角直接当作 U8g2 基线。
- 多行按显式换行拆分后逐行绘制；第一版不做隐式自动换行。
- 左/中/右对齐基于实际字形度量计算；调整字体会重新计算边界。
- 缺字列出字符和 Unicode 编码；不以浏览器系统字体偷偷补字。
- 第一版中文承诺范围为所选 U8g2 版本可表示的 BMP 字符；不承诺生僻扩展区字符、彩色 emoji、复杂文本 shaping。

**多边形规则：**

- U8g2 没有通用任意多边形绘制接口，需要实现并共享轮廓/填充算法。
- 填充边界约定、三角剖分或扫描线算法必须经过像素测试；不能直接用 HTML Canvas 填充作为最终结果。
- 矩形宽高为实际像素数，例如宽 10 对应 x 至 x+9，不是 x+10。

### 5.6 字库管理与中文转换

| 编号 | 要求 |
|---|---|
| FNT-01 | 展示内置字体目录：U8g2 符号、预览、实际像素度量、等宽/比例、覆盖范围、来源和许可 |
| FNT-02 | 字体按高度与风格筛选；首版内置字体清单须在开发阶段登记，不能将有限清单宣称为全量 U8g2 字体 |
| FNT-03 | 导入已有 U8g2 字库数据：支持约定的 C 数组/字符串字节表示或原始二进制，并读取真实格式与覆盖信息 |
| FNT-04 | C 字库导入只解析受支持的数据声明，禁止执行代码；不支持的宏、表达式或格式明确报错 |
| FNT-05 | 内置本地 TTF/OTF 导入，设置像素尺寸、提取字符集、生成单色字形与 U8g2 字库 |
| FNT-06 | 字符集来源：手动输入、文本文件、当前项目所有关联文本；去重、排序，并检查字体源缺字 |
| FNT-07 | 转换链路包括字形栅格化、度量、BDF 中间表示、U8g2 压缩编码；输出必须能被原生 U8g2 解码 |
| FNT-08 | 预览必须渲染生成后的字库数据，而不是仅显示 TTF 的网页效果 |
| FNT-09 | 展示字符数、像素尺寸、实际压缩字节数、来源、生成参数、兼容版本和许可记录 |
| FNT-10 | 字库生成支持进度、取消、失败详情；计算不得长期阻塞画布主线程 |
| FNT-11 | 文字变更导致缺字时提示重新生成；重新生成前后都检查引用，不能静默替换为别的字体 |
| FNT-12 | 删除被引用的字库需先替换引用或取消；导出仅包含所需自定义字库，内置字体通过 U8g2 符号引用 |
| FNT-13 | 完整项目包保存再次转换需要的源字体与参数；可选精简分享包须明确说明不能恢复源字体转换 |
| FNT-14 | 可选择电脑已安装字体或导入自定义 TTF/OTF。电脑字体访问仅由用户主动授权触发，列表可搜索并区分字体样式；拒绝授权/浏览器不支持时明确提示，不偷偷替换为系统默认字体 |
| FNT-15 | 可设置 0–255 取模阈值，通过笔画像素覆盖率二值化；降低阈值保留更多笔画，提高阈值保留更少笔画；完全透明背景始终为 0 |
| FNT-16 | 阈值与字号、源字体一并记录。改变参数后标明预览及下载仍对应上次生成的数据；重新生成的预览、BDF 与 C 字库使用同一阈值 |

首版 TTF/OTF 指常规静态轮廓字体。字体集合、可变字体、仅彩色位图字体不是默认支持范围；需检测后说明。像素字号是转换参数，不保证所有字形外接框高度等于该数字。

电脑字体使用桌面 Chrome/Edge 的 Local Font Access API 获取真实字体字节，并沿用同一转换链路。`file://` 可用性以浏览器实测为准；操作系统安装字体不等于授予应用分发权限。若浏览器返回 TTC 集合，按已选字体的 PostScript 名称提取对应静态成员并保留样式；找不到对应成员、成员不唯一或格式不支持时明确报错，不默认使用第一个成员，也不用网页字体近似或跨字体补字。自定义导入仍不包括直接选择 TTC 集合。阈值默认 128；阈值 0 表示保留所有非零覆盖的笔画像素，不包含空白背景。

不能直接把 TTF/OTF 交给 `bdfconv`；官方转换器处理的是 BDF 字体。推荐评估本地字体栅格化模块加 `bdfconv` WebAssembly，在浏览器内完成全部转换。具体工具选择须经过审计中的技术验证。

### 5.7 图片取模与资源管理

| 编号 | 要求 |
|---|---|
| IMG-01 | 导入 PNG、JPEG、BMP 等明确登记支持的常见静态图片；第一版不承诺动态图与 SVG |
| IMG-02 | 取模支持裁剪、目标尺寸、保持比例、灰度阈值 0–255、反色、透明像素背景选择、无抖动/有序抖动 |
| IMG-03 | 同时显示源图、取模预览、宽高、实际字节数及取模参数 |
| IMG-04 | 项目标准格式统一为 XBM：从左到右逐行、字节内 LSB-first、每行单独补齐到字节 |
| IMG-05 | 导入 XBM 文件、受支持的 C `uint8_t` 数组、原始二进制；缺少宽高或排列信息时要求用户填写，不猜测 |
| IMG-06 | 非 XBM 取模数据可按显式输入配置规范化：水平 MSB/LSB、垂直 8 像素分页及极性；只支持登记的排列，不宣称任意格式可导入 |
| IMG-07 | 校验数据长度、尺寸、行填充与尾部无效位；标准数据长度为 `ceil(width / 8) * height` |
| IMG-08 | 图片库支持缩略图、名称搜索、尺寸/字节数、重命名、复制、删除、替换、引用查询 |
| IMG-09 | 同一资源替换会影响所有引用，提交前显示影响清单；改变尺寸需提示重新检查布局 |
| IMG-10 | 删除被引用资源必须先替换或取消；不能留下不明确的空白占位图 |
| IMG-11 | 取模资源可独立导出 XBM/C 数组，完整项目保存源图与生成参数 |
| IMG-12 | 加载源图及修改裁剪、输出尺寸、阈值、透明背景、反色和抖动参数后自动刷新取模预览；显示倍率可调 1–32 倍且不改变数据，放大后支持滚动；非法参数阻止保存旧预览，明确保存后才替换项目资源 |
| IMG-13 | 左侧布局/图片面板切换，图片面板展示当前项目图片、搜索、点击添加到当前页及编辑入口；不默认提供第三方图标库 |

例如 13×3 图片应占用 6 字节，不是将 39 位整体连续压缩成 5 字节。输入 SSD1306 页缓冲不能直接当作 XBM。

### 5.9 离线与数据可靠性

| 编号 | 要求 |
|---|---|
| OFF-01 | 发布包不依赖 CDN、远程字体、网络 API 或在线编译；断网首次打开仍能使用全部第一版功能 |
| OFF-02 | `file://` 直接打开是正式验收环境；不能只验证开发服务器环境 |
| OFF-03 | 字库转换器、预览运行时及所需数据随发布包本地提供，不通过 `fetch` 外部文件才能启动 |
| OFF-04 | 浏览器存储不可用、空间不足、文件损坏时给出明确反馈，保留内存中的当前编辑数据并提供下载备份 |
| OFF-05 | 不上传用户图片、字体或项目；开发调试的网络请求也不得包含用户资源 |
| OFF-06 | 大任务可取消；导入体积、解压后体积、图片像素数、字形数量均有公开且可解释的限制 |

当前实现公开处理预算：项目包/总解压资源 128 MiB、清单 8 MiB、单源资源 32 MiB、源图 16M 像素、输出每边 512、多边形 256 点、组件坐标 ±2048、导入清单 1,000 页/每页 10,000 组件/10,000 资源。字体沿用 2,000 字符/5–64 px/65,535 输出字节。它们是输入处理保护，不是硬件容量或性能承诺；超限明确诊断。普通工作负载按 10 页、当前页 200 组件、50 图片测试。

| Project | schemaVersion、id、name、description、时间、display、pages、defaultPageId、resources |

| Page | id、name、exportSymbol、backgroundBit、orderedComponents |

组件使用资源 ID，不复制资源内容；页面顺序与组件顺序显式保存，不依赖对象键的偶然顺序。所有字节数据采用明确编码并校验。

## 7. 预览一致性要求

1. 最终预览输出为 1 bit framebuffer，不使用系统字体或抗锯齿 Canvas 作为最终像素真值。
2. 优先评估原生 U8g2 C 绘制核心编译为浏览器可用运行时，使用同一版本的字形解码和绘制规则。
3. 编辑器叠加层与最终 framebuffer 分离；拖拽命中区域可以比实际像素更宽，但不会被导出。
4. 自定义多边形辅助算法必须在浏览器预览和导出 UI 中保持同样边界规则。
5. 对照原生 C/C++ 绘制结果逐像素比较；相同测试输入要求差异像素数为 0。
6. 显式处理绘制颜色、字体透明/实底模式、位图模式、字形基线、裁剪和方向。

## 8. 非功能要求

- 发布版优先支持 Windows 上当前稳定版 Chrome、Edge；其他浏览器不默认宣称兼容。
- 操作界面以中文为主，U8g2 字体符号及代码 API 保留原名。
- 不执行导入的 C 代码、HTML 或字体脚本；导入名称与文本作为数据处理。
- 依赖、U8g2 源码、内置字体均记录版本与许可证；用户导入字体需要声明其拥有使用和分发权限。
- 不静默忽略缺字、解析失败、保存失败和转换失败；错误可定位到页面、组件或资源。
- 项目文件格式、导出 API、核心算法应有自动化测试。
- 性能建议基线：128×64、10 页面、当前页 200 组件、50 个图片、1,000 个待转换字符；这是测试样本，不是业务上限。
- 建议在记录硬件和浏览器的基准环境下，普通拖动帧间隔 p95 不超过 33 ms，普通属性修改至预览更新 p95 不超过 100 ms；大任务期间编辑线程仍响应取消操作。
- 发布包大小和转换耗时在技术验证后测量并登记，不预先给出没有依据的承诺。

## 10. 分阶段开发顺序

### 阶段 0：技术可行性验证

必须先验证：`file://` 离线加载、TTF/OTF 至 U8g2 字库、原生一致预览、C/C++ 双目标、AVR 闪存读取、多边形边界一致性。

任何关键项未通过，不进入完整编辑器开发；记录阻塞与替代方案，用户确认范围或实现调整后再继续。

### 阶段 1：项目与编辑骨架

项目包、保存恢复、屏幕参数、多页面、组件树、几何组件、属性编辑、拖拽、撤销、基础原生预览。

### 阶段 2：图片资源闭环

取模、已有位图导入、图片库、绑定与引用校验、图片预览和资源导出。

### 阶段 3：文字与字库闭环

内置 ASCII 字体目录、U8g2 字库导入、TTF/OTF 中文转换、缺字诊断、字体资源管理。

### 阶段 4：代码导出与整体验收

双目标代码包、集成文档、许可证记录、页缓冲测试、像素对照、离线发布与性能验收。

上述是内部开发顺序，不代表只完成几何组件就宣称满足第一版。第一版交付必须完成中文转换、图片取模和两个导出目标。

## 13. OLED 组件与基础能力扩展

字库命名增量：自定义字库源码符号由资源名称生成，不再使用 UUID；选择字体文件后默认资源名去掉扩展名，允许修改；非法标识字符确定性编码，重复名称确定性分配未占用序号。生成/导出的 C 字库逐字形记录增加字符和 Unicode 注释，字节不变；所有平台声明与调用同步，内置字体保持官方符号。

图片命名增量：三平台图片声明、定义、绘制调用及独立 XBM 下载统一使用 `oled_bitmap_` 加规范化资源名称，不使用 UUID。图片扩展名去除，字符编码与重名保护复用字库机制；内部资源 ID、组件引用和位图数据保持不变。

用户确认实现全部推荐组件和基础能力，按阶段交付。变量绑定在编辑器配置示例值，导出通过独立数据结构传值，暂不做事件；第一版静态范围不限制本次扩展需求。
